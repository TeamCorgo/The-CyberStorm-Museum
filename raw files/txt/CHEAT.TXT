WARNING:  !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

This document describes several miscellaneous options and cheat codes 
for MissionForce: CyberStorm v1.1.   Some of these codes enable or 
disable features that have been requested by our users.  Some codes 
can prove useful when replaying your career with different tactics.  
If you prefer to play the game unspoiled, you may wish to skip the 
bulk of this document.

========================================================================
HOW TO USE CYBERSTORM CHEAT CODES:
========================================================================

Most of these codes are activated by editing the CSTORM.INI file 
located in the MissionForce: CyberStorm directory, and adding a line 
there that causes a new menu item to appear.  We chose this approach 
because the code only has to be entered once, and are then quick to 
use repeatedly.

You may use any editor that can edit regular text files such as Notepad.
You may use WordPad or a professional word processor if you make sure
to save the file as a text file.

Steps:
   1) Run your text editor (like Windows NotePad)
   2) Load CSTORM.INI from the directory that you installed CyberStorm 
      into.  (Select 'Open' from the 'File' menu and use the Windows95 
      Open dialog to open CSTORM.INI, which is often in the 
      C:\SIERRA\CSTORM directory)
   3) Pick a code from the list below. 
      Example: I'll Buy That For A Credit
   4) Type the code on a line by itself somewhere in the file, being 
      careful to spell correctly.  You do not need to worry about 
      capitalization.
   5) Repeat steps 3 & 4 until done.
   6) Save the text file
   7) Run CyberStorm and you will have new menu options
      available at certain times.

VERY IMPORTANT CLARIFICATION:
========================================================================
The codes listed here are useful only for the single-player career.
You will not be able to use the cheats during a multiplayer/hotseat 
battle, unless noted.


========================================================================
Category:   Optional Features
========================================================================
            In CyberStorm v1.1, we have taken the liberty of adding most
            of these optional feature codes to your CSTORM.INI for you.
            If you decide you don't like one of these features, you
            may remove the line that adds that feature.
========================================================================

Code:       2112 
Available:  on HercBase screen
NOTE:       Requires version 1.1!   Is added automatically by patch.
Function:   Entering this code adds two items to the menu bar.
            The first lets you repair all your hercs and bioderms 
            quickly.  The other lets you autolink any pilots you forgot
            to.  Both of these are useful when you are in a rush.

Code:       I changed my mind
Available:  on HercBase screen
NOTE:       Requires version 1.1!   Is added automatically by patch.
Function:   Entering this code adds three items to the menu bar
            that let you change the difficulty level on-the-fly.
            If you decide that Easy is too easy or Hard is too hard,
            change it to suite your needs.   This will change the
            currently loaded career, and remain in effect until the
            changed again through the menu.

Code:       Don't just stand there!
Available:  Affects firing during battle movement (SINGLE-PLAYER ONLY!)
NOTE:       Requires version 1.1!   Is added automatically by patch.
Function:   Turn on a more advanced form of opportunity fire that
            will cause units to fire on an enemy as their enemy 
            approaches.  They will only fire if they have saved energy 
            for shots.  Since this changes the game somewhat, you have 
            the option of removing this feature by removing the code 
            from the CSTORM.INI.
            
            NOTE: This code is used for single-player games only.  In 
            multiplayer or Hotseat games, there is an option on the 
            launch screen to turn OpFire on or off.

Code:       Leave me alone
Available:  Affects battle startup
NOTE:       Requires version 1.1!  Is NOT added by the patch.
Function:   Version 1.1 has support to automatically detect if your 
            multiplayer opponents have hacked their forces to have 
            illegal unit configurations.   It will warn you, so that 
            you may deal with the situation however you choose.  
            HOWEVER, if you find these warnings annoying or problematic,
            you may turn them off by adding the 'Leave me alone' code 
            to your CSTORM.INI.

            NOTE: You can turn off these warnings on your >OWN< machine, 
            but you can't turn off messages on >OTHER< machines that 
            identify you as cheating.  So, play fair!  CyberStorm is a 
            battle of tactics and strategies -- not a battle of 
            hex-editors.

Category:  Misc. / Unusual features (Easter-Eggs)
========================================================================

   Name a pilot: ELSA
      (The name of a programmers dog)

   Type ELSA on beginning of Connect-screen chat line to bark 
      at your opponents.

   Click on some of the background monitors while in 
      BioVat, MedVat, VR, or Link areas.

   Name a Bioderm Kurosh to have him transformed into Kaesar's 
      Genetic Matrix.

   There is a way to bring more than 12 units into a multiplayer game.
      First, load up one of your single-player forces with more than
         12 units.   
      Second, name one of the hercs on that force "Big John" 
         (without the quotes).
      Third, load that force when starting a multiplayer game.  When you
         get to the battle, all the units will be there.
      
      IMPORTANT NOTE: Please use the 'Big John' sparingly and carefully!
         There are known problems that occasionally happen you use it
         with many players or a large cybrid presense at the same time.  
         Sometimes two forces will overlay and try to occupy the same 
         space and the game will stop.  It also can make games slow.
