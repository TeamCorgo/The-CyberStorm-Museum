Command Bioderm

On the field, a Command Bioderm can boost the faltering Genetic Stability of unstable Bioderms by moving near them. Command Bioderms can bolster the stability of any Bioderm within three hexes of themselves (including themselves) by half of the Command Bioderm’s Command rating. Some limited boost is possible beyond three hexes, but at a greatly reduced level. Multiple Command Bioderms do have a cumulative effect on an unstable Bioderm, each boosting the unstable ’derm at full effect.

Only certain Bioderms are created with Command skill. This skill can often be increased in VREC, though it is very expensive. Command skill can never exceed 40.
